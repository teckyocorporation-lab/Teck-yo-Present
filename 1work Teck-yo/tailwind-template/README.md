# Plantilla Tailwind CSS

Plantilla de tienda online utilizando Tailwind CSS con diseño moderno y responsive.

## 🚀 Características

- **Framework**: Tailwind CSS vía CDN
- **Diseño**: Moderno y limpio
- **Responsive**: Mobile-first approach
- **Iconos**: Font Awesome 6.0
- **Colores**: Paleta Indigo/Purple

## 📁 Archivos

- `index.html` - Página principal con toda la funcionalidad

## 🎨 Componentes Incluidos

### Header
- Logo de la tienda
- Navegación responsive
- Búsqueda y carrito
- Botón de login

### Hero Section
- Título principal
- Subtítulo descriptivo
- Botón de llamada a la acción
- Gradiente de fondo

### Productos
- Grid responsive de productos
- Tarjetas con hover effects
- Precios y botones de agregar
- Imágenes placeholder

### Características
- Iconos con gradientes
- Descripción de beneficios
- Layout en 3 columnas

### Footer
- Enlaces organizados
- Información de contacto
- Copyright

## 🛠️ Uso

1. Abre `index.html` en tu navegador
2. Personaliza los textos, colores e imágenes
3. Modifica las clases de Tailwind según necesites

## 🎯 Personalización

### Cambiar Colores
```html
<!-- Cambiar color primario de indigo a blue -->
class="bg-indigo-600" → class="bg-blue-600"
class="text-indigo-600" → class="text-blue-600"
```

### Modificar Layout
```html
<!-- Cambiar grid de 4 a 3 columnas -->
grid-cols-4 → grid-cols-3
```

### Ajustar Espaciado
```html
<!-- Cambiar padding -->
py-16 → py-20
px-4 → px-6
```

## 📱 Breakpoints Tailwind

- `sm:` - 640px+
- `md:` - 768px+
- `lg:` - 1024px+
- `xl:` - 1280px+

## 🔧 Clases Útiles

### Layout
- `container` - Contenedor centrado
- `max-w-7xl` - Ancho máximo
- `mx-auto` - Centrado horizontal

### Grid
- `grid` - Display grid
- `grid-cols-1` - 1 columna
- `grid-cols-4` - 4 columnas
- `gap-8` - Espacio entre elementos

### Flexbox
- `flex` - Display flex
- `justify-between` - Espacio entre elementos
- `items-center` - Alineación vertical

### Colores
- `bg-indigo-600` - Fondo indigo
- `text-white` - Texto blanco
- `hover:bg-indigo-700` - Hover effect
