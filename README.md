# Teck-yo - Transformamos Ideas en Realidad

Sitio web profesional para Teck-yo, una empresa de desarrollo de software que lleva las ideas del concepto a la realidad.

## 🚀 Características

- **Diseño Moderno**: Interfaz elegante con paleta de colores profesional
- **Efectos Visuales**: Partículas animadas, estrellas fugaces y líneas de neón
- **Logo Interactivo**: Efectos de hover con partículas orbitantes tipo átomo
- **Responsive Design**: Optimizado para todos los dispositivos
- **Animaciones Suaves**: Transiciones y efectos visuales profesionales

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones avanzadas)
- JavaScript (Canvas API para efectos de partículas)
- Diseño Responsive

## 📱 Responsive Design

- **Desktop**: Experiencia completa con todos los efectos
- **Tablet**: Adaptado para pantallas medianas
- **Mobile**: Optimizado para dispositivos móviles

## 🌟 Efectos Especiales

- **Partículas Orbitantes**: Al pasar el mouse sobre los emojis del logo
- **Estrellas Interactivas**: Reaccionan al movimiento del mouse
- **Líneas de Neón**: Efectos de pulso y estelas
- **Gradientes Animados**: En el texto principal del logo
